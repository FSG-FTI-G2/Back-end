# Document Retrieval APIs

### Quick start

> ⚠️ Get the .env file before run

- Start Application

```sh
docker compose up
```

- Develop synthensis

```sh
docker compose watch
```

### Run test

```sh
python -m unittest discover -s ./test -p 'test_*.py'
```
